# AGENTS.md｜大疆机试二：三角色协作协议

> 适用于本 Java 项目根目录。**本文件不是原版任务书的替代品**。如项目已有 AGENTS.md，请先合并，勿直接覆盖。

## 优先级与权威分工

- **原版《G班机试2.md》**：业务规则、数据要求、评分、提交物、GUI 验收、技术硬约束的最高依据。
- **《大疆机试二_AI主导开发与伴学指导书.md》及本文件**：工具角色、协作边界、进度、版本和验证规范的依据。
- **真实 `order.json`、`DJIProductDemo` 与项目源码**：事实依据；与任务书冲突时标记差异，不能擅自改需求。
- **获用户确认的 `docs/ARCHITECTURE_BLUEPRINT.md` 和 `docs/DECISIONS.md`**：已批准的架构与业务决策；未知事项不得猜测为已批准。

原版中面向学生的“AI 辅助、提交者解释/验证”等表述是考核和责任要求，不是限制 AI 自主开发的工作方式规范。用户仍负责真实验收、提交责任与关键决策。

## 固定角色

- **Zed（高端模型）**：核心架构、规划、重大结构复核、最终独立质量审计；原则上**只读信息、输出方案**，不教课，不主力编码。
- **ZCode（GLM-5.3-Flash）**：唯一主力开发与测试 Agent；代码落盘、构建、测试、排错、GUI、文档、Git 检查点均由其负责。不要每个操作都停下来请示或长篇教学。
- **ChatGPT**：按用户提供的实际 GitHub commit/代码进行伴学解释、技术取舍讨论和反馈整理；不默认介入日常编码。
- **用户**：需裁决业务歧义/重大产品体验、检查必要的本地 GUI、负责本地 GitHub 推送与最终提交。

## 默认工作路径

1. ZCode 只读勘察，填 `docs/00-基线与输入清单.md`，记录 Git 与真实基线。
2. Zed 基于实际事实出 `docs/ARCHITECTURE_BLUEPRINT.md`、`docs/IMPLEMENTATION_PLAN.md`、需求追踪；重大歧义交用户决定。
3. ZCode 根据已批准架构实施并验证十阶段任务，按模块更新状态与 Git 提交。
4. 用户按模块通过 GitHub/文件找 ChatGPT 学习；非阻断性讨论不影响 ZCode 持续开发。
5. Zed 重大架构复核和终验审计，ZCode 修复，用户实机验收与提交。

## 安全边界

- 保留用户原始文件、未提交变更、老师配发数据和 Demo；禁止擅自 `git reset --hard`、`git push --force`、删除仓库、全局安装修改或未经授权远程推送。
- 不将密钥、个人路径、许可证敏感资料和无授权课程文件自动公开到 GitHub；上传前应由用户确认公开范围。
- 不因方便测试而更改原始 `order.json`；另建测试 fixture。
- 对需要人工决定的事项，给出来源、两种结果、推荐方案，并继续非阻断任务。

## 工程质量硬要求

- Java 领域模型封装及不变量、七个生产基地的**抽象工厂**、四个促销策略的**策略模式**、线程安全单例递增序列号和耗尽错误。
- 金额以 `BigDecimal` 计算，禁用金额浮点；按真实币种保留货币单位，严禁混币汇总。
- JSON 字段与型号根据真实文件，异常和失败必须明确；无效路由不得 `null`/静默跳过。
- 真实且有业务意义的 Stream 组合筛选、`groupingBy`、扁平化与函数式接口。
- Swing 七项功能；UI/服务层解耦；所有 Swing 更新在 EDT，文件/批处理不能阻塞 EDT。
- JUnit 等可重复测试；至少一个真实故障的“复现—修复—回归”证据；真实 GUI 验收不得由想象代替。

## 状态与交付文件

- `docs/01-需求追踪矩阵.md`：每项原版要求映射实现、验证与状态。
- `docs/ARCHITECTURE_BLUEPRINT.md`、`docs/IMPLEMENTATION_PLAN.md`：Zed 规划；ZCode 按获批版本执行。
- `docs/DECISIONS.md`：业务裁决、结构性架构变更、临时假设及其状态。
- `docs/PROGRESS.md`：当前代码版本、已做/待做/阻断事项。
- `docs/VERIFICATION.md`：真实测试命令、退出码、报告路径、版本与 GUI 证据。
- `docs/HANDOFF_FOR_CHATGPT.md`：每模块真实路径、类方法、调用链、测试事实、1–3 个学习锚点。

**永远区分：已实际验证 / 仅静态分析 / 待裁决 / 受环境限制 / 未实施。** 没有运行证据不能宣称通过。用户最终需要能够理解、解释并验证提交的工作。
