# AI 使用说明｜真实过程记录模板

> 原版任务书要求提交 AI 使用说明。以下是**预设角色计划，不是实际使用过程**，交付前由 ZCode 根据真实执行记录修订。

## 实际使用工具与职责

| 工具/模型 | 计划用途 | 实际使用时间、输入资料与产物 | 人工/自动验证方式 |
|---|---|---|---|
| Zed / 具体实际模型待填写 | 领域架构、接口规划、独立质量审计 | 待真实记录 | 用代码、测试和任务书核对 |
| ZCode / GLM-5.3-Flash | Java 编码、测试、GUI、缺陷修复 | 待真实记录 | 实际构建、JUnit、界面验收 |
| ChatGPT / 实际模型待填写 | 代码讲解、方案讨论、用户反馈 | 待真实记录 | 与真实版本/日志核对 |

## 最终撰写须覆盖

- AI 参与了哪些环节；具体产出对应何处，如何改动和验证；不得空泛表述“用了 AI”。
- 用户提出过哪些真实设计/业务意见；不能虚构人工参与。
- 曾发生的至少一个真实问题如何复现、如何修复、如何回归通过（亦可在设计说明详写）。
- 编译命令、测试报告、GUI 七场景、README；未执行的证据必须如实说明。

> **责任声明**：最终提交者应检查可运行性、设计合理性、真实测试与说明；AI 主导实施不免除原版任务书规定的解释与验证责任。
