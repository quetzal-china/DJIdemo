# GUI 验收操作卡｜照着点、照着截，15 分钟拿齐全部证据

> 用法：启动 GUI 后按顺序做 G1→G7。每做完一项，把截图存到 `docs/evidence/`（文件名已给好），
> 然后在本文末尾的"执行记录"打钩。全部做完后告诉 ZCode，由它把证据登记进 `VERIFICATION.md`。

**启动命令**（djProject 目录下）：

```bash
java -cp "target/classes:target/dependency/*" com.dji.ui.DJIOrderApp
```

**截图保存位置**：`docs/evidence/`（目录已建好）
**命名规则**：`G1_启动加载.png`、`G3_组合筛选.png`……（下方每步都标了文件名）
**加分项**：如果方便，用 OBS/系统录屏把 G1–G7 连续录一遍存为 `docs/evidence/全程录屏.mp4`——一段视频胜过七张截图。

## G1｜启动与打开文件 → `G1_启动加载.png`

1. 用上面命令启动（**不带参数**），窗口出现后应自动加载 `order.json`；
2. 检查：订单表格出现 **14 行**；状态栏显示 `加载成功: …\order.json（有效 14 笔）；尚未执行生产`；
3. 再点一次【打开订单文件】，用弹出的选择器重新选一次 `src/main/resources/order.json`（证明 JFileChooser 可用）；
4. 📸 截全窗口。

## G3｜组合筛选 → `G3_组合筛选.png`

1. 关键字输入 `李四`，地区选 `中国大陆`，状态选 `待处理`，点【筛选】→ 应只剩 **2 行**（0002、0005）；
2. 关键字改为 `Elizabeth`，地区改 `北美`，点【筛选】→ 应剩 **1 行**（2025102900009，客户名含零宽字符仍能命中）；
3. 关键字输入一个不存在的词（如 `xyz`）点【筛选】→ 表格空，状态栏提示"筛选无匹配结果"；
4. 点【清除条件】→ 恢复 14 行。
5. 📸 截"李四+中国大陆=2 行"的画面（第 3 步无匹配提示也值得截一张：`G3_无匹配.png`）。

## G4｜订单详情与生产基地 → `G4_订单详情.png`

1. 选中订单 **2025102900011**（Alessio，欧洲，3 条明细）；
2. 查看"订单详情与生产结果"Tab，应显示：
   - 明细：Inspire 3 ×1、Mavic 4 PRO ×1、T70 ×4；
   - 促销候选：其他地区满件折扣 优惠 EUR 6957.45 应付 EUR 39425.55（← 最优）；
   - 基地预览：**德国斯图加特基地**（Inspire 3 / Mavic 4 PRO）、**顺德工厂**（T70）。
3. 📸 截详情 Tab。

## G5｜生产与序列号 → `G5_生产结果.png`

1. 选中任意订单点【处理选中订单】，或直接点【处理全部订单】；
2. 检查：状态栏出现"生产进行中 x/14"再到"生产处理完成：成功 14 笔"；表格"状态"列全部变`已生产`；
3. 详情 Tab：每条明细显示 基地 | 型号 | 完成 n/n | SN 列表，序列号从 `DJI-00000001` 连续递增；
4. **幂等验证**：再点一次【处理全部订单】→ 状态栏提示已生产订单"幂等跳过"，序列号不翻倍；
5. 📸 截生产后的详情 Tab（含 SN）+ 状态栏。

## G7｜坏文件反馈 → `G7_坏文件反馈.png`

> 2026-11-07 备注：首次验收时 JFileChooser 未定位到深层 fixture，最终以②的 CLI 参数方式完成；
> 若要在界面内选择，可：
> ① 对话框内从 `resources` 逐级导航：点 Look In 下拉选 `djProject` → `src` → `test` → `resources` → `fixtures` → 选 `invalid_orders.json`；
> ② 直接用 CLI 参数启动坏文件演示：`java -cp "target/classes:target/dependency/*" com.dji.ui.DJIOrderApp src/test/resources/fixtures/invalid_orders.json`

1. 点【打开订单文件】，选择 `src/test/resources/fixtures/invalid_orders.json`；
2. 检查：状态栏显示"有效 1 笔，异常 14 笔"；"加载错误汇总"Tab 列出 14 条错误（每条含订单号+明细序号+字段+原因）；程序**不崩溃**，表格仍可操作；
3. 再打开 `order.json` 恢复正常，确认能继续筛选/生产；
4. 📸 截错误 Tab + 状态栏。
